## 0. 执行说明

### 0.1 优先级与通过标准

| 优先级 | 含义                    | 发布要求             |
| --- | --------------------- | ---------------- |
| P0  | 主流程、数据安全、会导致点错位置或无法运行 | 必须 100% 通过       |
| P1  | 重要功能、常用配置、异常提示        | 通过率 >= 95%，不允许失败 |
| P2  | 兼容性、边缘场景、体验问题         | 记录结果，允许带已知问题发布   |

阻断发布的条件：任一 P0 用例失败；或出现数据丢失、工程无法打开、点击位置系统性偏移。

### 0.2 结果标记

| 标记  | 含义                              |
| --- | ------------------------------- |
| 通过  | 实际结果与预期一致                       |
| 失败  | 实际结果与预期不一致，需提缺陷                 |
| 阻塞  | 前置条件不满足（如无第二显示器、无 VLM 凭证），需注明原因 |
| 不适用 | 当前构建不包含该能力                      |

至少覆盖以下组合，每条用例只需在标注的环境执行一次并记录。

| 环境编号  | 系统              | 显示缩放 | 显示器                | 输入方式                      |

| ENV-2 | Windows 11 23H2 | 125% | 单屏                 | PyAutoGUI                 |

### 0.4 测试数据准备

| 编号   | 数据                   | 准备方式                                                                                            |
| ---- | -------------------- | ----------------------------------------------------------------------------------------------- |
| P-01 | 正常工程 `demo_normal`   | 开始 -> 图像匹配 -> 左键点击 -> 结束；模板为记事本工具栏按钮截图                                                          |
| P-02 | 多尺度工程 `demo_scale`   | 在 P-01 上开启“多尺度匹配”，范围 `0.85,1.15`，档数 5                                                           |
| P-03 | 异常树集合 `demo_invalid` | 分别准备：空树、根节点缺失、未知节点类型、多父节点、环形树、模板缺失、不可达节点、连线指向不存在节点                                              |
| P-04 | 缩略图素材                | 400x200 PNG、100x50 PNG、损坏的 `.png`（内容为文本）、透明背景 PNG                                               |
| P-05 | BOM 文件集合             | 对 P-01 的 `tree.json`、`project.json`、`config/settings.json`、`assets/manifest.json` 各生成一份带 BOM 副本 |
| P-06 | 窗口尺寸工程 `demo_window` | 开始节点勾选“绑定窗口”，窗口标题为 `无标题 - 记事本`，勾选“自动还原窗口尺寸”                                                     |
| P-07 | VLM 工程 `demo_vlm`    | 三个 VLM 节点各一条链路，节点内填写可用的 `base_url`、`api_key`、`model`（条件用例）                                      |
| P-08 | UIA 工程 `demo_uia`    | UIA 采样/UIA 状态检查，目标为 Windows 计算器                                                                 |

生成 BOM 文件参考命令（PowerShell，逐文件执行）：

```powershell
$bom = [byte[]](0xEF,0xBB,0xBF)
$raw = [IO.File]::ReadAllBytes('tree.json')
[IO.File]::WriteAllBytes('tree_bom.json', $bom + $raw)
```

### 16.6 备注

- `plugin load` 只在当前 CLI 进程内生效，后续进程执行 `plugin unload` 会提示“未找到插件”，属于无状态命令的既有语义，不计缺陷。
- J-09 原预期“`--offset` 等同 `--origin`”与实现不符；实现中 `--offset` 是客户区原点，用于换算 `coord_client`，已按实际语义修正用例描述并判通过。
