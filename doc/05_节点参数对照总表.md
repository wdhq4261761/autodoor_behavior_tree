**多尺度匹配说明（V2.0.0 新增）**

| 项 | 说明 |
| --- | --- |
| 作用 | 模板按 `scale_range` 内均匀取 `scale_steps` 档缩放后逐档匹配，覆盖显示缩放 / DPI 差异导致的尺寸变化 |
| 缺 1.0 时 | 范围包含 1.0 但档位未落在 1.0 上时，自动补入 1.0 并重排，避免丢原始尺寸 |
| 代价 | 耗时随档数线性增长（单档为一次全图 `matchTemplate`），仅在已知存在缩放差异时开启 |
| 日志 | 命中且比例非 1.0 时输出 `多尺度命中 scale=1.10`，可据此反推当前 DPI 缩放 |

**target_color 支持的书写格式（V2.0.0 起）**

| 格式 | 示例 | 说明 |
| --- | --- | --- |
| 十六进制六位 | `#d93b3b` / `d93b3b` | 推荐，颜色选择器输出的就是这种 |

| RGB 函数式 | `RGB(217, 59, 59)` | 大小写不敏感 |
| 逗号三元组 | `217,59,59` | 兼容旧配置 |

> 全部格式均无法解析时回退为红色 `(255,0,0)`，请在日志中确认实际生效的颜色。

## 四、插件节点（V2.0.0 起）

插件节点在树文件中的类型名格式为 `{插件名}.{节点类型}`，例如 `uia_bridge.UIASampleNode`。
不确定名字或参数时，执行：

```bash
autodoor-cli plugin nodes        # 列出全部插件节点 + 参数 schema
autodoor-cli plugin list         # 只看插件清单
```

### 1. UIA 采样节点 (uia_bridge.UIASampleNode)

枚举窗口控件树，取目标控件的矩形并输出坐标。设计用途是**制作期跑一次**把控件位置固化，运行期直接点，不要放进高频循环。

| 参数名（中文） | 参数名（英文） | 默认值 |
| --- | --- | --- |
| 窗口句柄（0 表示按标题查找） | hwnd | 0 |
| 窗口标题 | window_title | 无 |
| 窗口类名 | window_class | 无 |
| 控件名称 | control_name | 无 |
| 控件类型 | control_type | 无 |
| 名称匹配方式 | name_mode | exact（可选 contains / regex） |
| 取第几个匹配项 | nth | 0 |
| 单次遍历控件数上限 | max_nodes | 3000 |
| 输出坐标类型 | output_mode | client（可选 screen） |
| 坐标写入变量 | position_key | 无 |
| 同时写 last_detection_x/y | write_scalar | false |
| 写入素材清单 | write_manifest | false |
| 素材清单路径 | manifest_path | assets/manifest.json |
| 素材名（留空用控件名） | asset_name | 无 |
| 语义说明 | semantic | 无 |
| 项目根目录 | project | . |

| 参数名（中文） | 参数名（英文） | 默认值 |

### 5. VLM 读取节点 (vlm_vision.VLMReadNode)

| 参数名（中文） | 参数名（英文） | 默认值 |
| --- | --- | --- |
| 要读取什么 | question | 画面左上角显示的得分数字 |
| 读取区域 | region | 全屏 |
| 写入变量名 | write_to | vlm_text |
| 缓存有效期(ms) | cache_ttl_ms | 1000 |
| 单次运行调用上限 | max_calls_per_run | 10 |
| 请求超时(ms) | timeout_ms | 15000 |
| 端点 / 密钥 / 模型 | base_url / api_key / model | 留空沿用全局 AI 配置 |

> 三个 VLM 节点共用同一套预算闸：`max_calls_per_run` 按「单次运行」计数，超限后节点直接返回失败而不发请求；`cache_ttl_ms` 内命中相同画面（phash 相近）时复用上次结果，不产生调用。
